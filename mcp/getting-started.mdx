Install Private Clubs in your AI app, check that it works, then ask about clubs. Free, no account or API key needed.

## Install Private Clubs

Paste this line into your AI app:

```text
Set up the Private Clubs MCP for me: read https://www.theprivateclubs.com/mcp/setup.md and follow the steps for this app
```

Agent apps such as Claude Code, Codex and Cursor run the setup for you, once you agree to each change. Chat apps such as Claude and ChatGPT walk you through the clicks.

Prefer a plugin? Download the one for your app. Each plugin includes the Private Clubs skill and the MCP connection, and both the plugin and its skill are named `private-clubs`.

## Confirm the connection

Start a new session if your app needs one, then ask:

```text
Search clubs in Florida
```

The `search_clubs` tool answers with clubs and a link to each profile.

## Ask about clubs

Ask your first question:

```text
Find yacht clubs in Florida
```

`search_clubs` returns up to 25 listed clubs, best known first. Narrow by type and place to get the clubs you want. Try another:

```text
Which equestrian clubs are listed in Kentucky?
```

## Look up one club

Ask about a single club by name:

```text
Show me the profile of Desert Forest Golf Club
```

`get_club` fits this ask. It takes the club's slug, such as `desert-forest-golf-club`, which `search_clubs` returns. It answers with the club's course, amenities, waitlist status and a link to its profile.

Private Clubs never returns membership fees. Account holders see fees on each club's profile at theprivateclubs.com.
