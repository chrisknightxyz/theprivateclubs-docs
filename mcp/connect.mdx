Private Clubs runs its MCP server at one address:

```text
https://www.theprivateclubs.com/api/mcp
```

Add it under the server key `private-clubs`, with the display name Private Clubs. The server uses Streamable HTTP. Free, no account or API key needed. For pictures of each step, see the [setup page](https://www.theprivateclubs.com/mcp).

## Use the setup line

Paste this line into your AI app:

```text
Set up the Private Clubs MCP for me: read https://www.theprivateclubs.com/mcp/setup.md and follow the steps for this app
```

Your app reads the setup steps on theprivateclubs.com and follows the section for itself.

- **Agent apps** (Claude Code, Codex, Cursor, OpenClaw and Hermes) show you each command or config change and run it once you agree. They add the server beside your other MCP servers and keep them.
- **Chat apps** (Claude, ChatGPT, Grok and Perplexity) cannot add a connector themselves, so they tell you the clicks.

## Another app

Add a remote MCP server in your app's settings with these values:

| Setting | Value |
|---|---|
| Name | Private Clubs |
| Server key | `private-clubs` |
| Address | `https://www.theprivateclubs.com/api/mcp` |
| Transport | Streamable HTTP |
| Authentication | None |

## Replace an older entry

Added `clubs` before? It is the same server under an earlier name. Replace it with `private-clubs`, so your app does not show the tools twice.

In apps with a command line, remove the old entry first, then add Private Clubs as your app's tab shows:

```bash
claude mcp remove clubs
codex mcp remove clubs
openclaw mcp remove clubs
```

In Cursor and Hermes, replace the `clubs` entry in the config file with the `private-clubs` entry. In Claude, ChatGPT, Grok and Perplexity, replace the older connector with Private Clubs.

## Check it worked

Start a new session if your app needs one, then ask:

```text
Search clubs in Florida
```

The `search_clubs` tool answers with clubs and a link to each profile. No Private Clubs tools? See [Troubleshooting](/mcp/troubleshooting#private-clubs-tools-do-not-appear).

## Call the server without an app

You can call the server from a terminal. It is stateless, so a tool call needs no session and no `initialize` step. Send JSON-RPC over POST:

```bash
curl -X POST https://www.theprivateclubs.com/api/mcp \
  -H "content-type: application/json" \
  -H "accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

The answer is JSON that lists the five tools and their input schemas. To run a tool, send `tools/call` with the tool's `name` and its `arguments` in `params`. A GET request returns 405, because the server answers POST only.

Next, see each tool's parameters in [Available tools](/mcp/tools), or fix a problem in [Troubleshooting](/mcp/troubleshooting).
