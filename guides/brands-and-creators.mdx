Brands and creators use Private Clubs to see which clubs of one type sit in a region, before research or outreach. Start in your AI app for a quick look, then search further with the API. [Install Private Clubs](/mcp/connect) first, or read the [API quickstart](/api).

## Start in your AI app

```text
Which equestrian clubs are listed in Kentucky?
```

Two tools fit a list like this:

- `search_clubs` with `type` and `state` returns up to 25 clubs, best known first.
- `get_clubs_by_state` with `state` and an optional `type` returns up to 100 clubs, best known first. It covers US states and Canadian provinces.

```text
List the golf clubs in Texas
```

Both tools match `type` exactly against the club's stored type, so `golf` does not include `country_club`. A list that stops at exactly 25 or 100 clubs may be cut off. The API returns more, up to the first 500 results of a search.

## Search further with the API

The API returns up to 50 clubs a page, A to Z by name, and the first 500 results of a search. This request lists the first 50 golf clubs in Texas. It needs `jq`.

```bash
curl -s "https://www.theprivateclubs.com/api/v1/clubs?type=golf&state=Texas" \
  | jq -c '.clubs[] | {name, slug, city, type, waitlist_status}'
```

Add `page=2` and up for the next 50, as far as page 10. A page past result 500 answers 403 with `data_feed_required`. Golf clubs in Texas run past 500, so add filters such as `waitlist` or `q` to find the clubs you need.

In the API, `type` groups related types, so `type=golf` also returns country clubs. See [club types](/reference/club-types) for the groups.

Call the API from a terminal or a server. It sends no CORS headers, so browser calls from another site fail.

<Note>
Paging through results to collect the directory, storing a substantial part of it or building a dataset from it is bulk use. It needs a paid monthly data feed license: email support@theprivateclubs.com. See [Bulk data](/api/usage-limits#bulk-data).
</Note>

## Filter by amenities

```text
Find clubs in Florida with a golf course and a spa
```

The tool that fits is `search_clubs`, with `state` set to `Florida` and `amenities` set to `["golf_course", "spa"]`. The `amenities` argument takes stored amenity codes, and a club must have every code you send.

Matching is exact, so `Spa` and `spa` are different codes. Take real codes from a live result first, such as a `get_club` answer, and do not guess them.

API rows carry the same `amenities` field, so you can filter the rows a search returns in your own code.

## Use the list well

Private Clubs never returns membership fees. Account holders see fees on each club's profile at theprivateclubs.com.

Cite Private Clubs (theprivateclubs.com) and link the club's profile. See the [data license](https://www.theprivateclubs.com/data/license) for the attribution format and bulk use.

Looking up, searching and comparing clubs through the MCP server and the API is free, including for work, with credit to Private Clubs and a link to each club's profile. Bulk download, scraping, mirroring or storing the directory, building a dataset from it, training AI models on it or reselling it needs a paid monthly data feed license: email support@theprivateclubs.com.
