AI apps that use Private Clubs answer from your club's listing on theprivateclubs.com. Follow these tasks to read that listing the way they do, see the clubs listed around you and claim the listing so you can keep it current. [Install Private Clubs](/mcp/connect) in your AI app first, or call the [API](/api) from a terminal.

## Find your club's slug

Every club has a slug, a short ID such as `desert-forest-golf-club`. The other tools need it.

<Tabs>
  <Tab title="MCP">
    ```text
    Search clubs for Desert Forest Golf Club
    ```

    The tool that fits is `search_clubs`, with `query` set to your club's name. The slug is in each result. It is also the last part of the profile `url`, as in `https://www.theprivateclubs.com/clubs/arizona/desert-forest-golf-club`.
  </Tab>
  <Tab title="API">
    ```bash
    curl "https://www.theprivateclubs.com/api/v1/clubs?q=Desert%20Forest"
    ```

    `q` matches part of the club name. Each row in `clubs` carries its `slug`.
  </Tab>
</Tabs>

## Read your profile

```text
How does Desert Forest Golf Club's profile read on Private Clubs?
```

The tool that fits is `get_club`, with `slug` set to your club's slug. It returns what AI apps see: name, city, state, country, type, description, waitlist status, course data, founded year, member count, amenities, website, phone, hero image and the profile `url`. It never returns fees.

A field with no value comes back as `null`. Those fields show you what your listing is missing.

## See the clubs listed in your state

<Tabs>
  <Tab title="MCP">
    ```text
    Which yacht clubs are listed in Florida?
    ```

    The tool that fits is `get_clubs_by_state`, with `state` set to a US state or Canadian province and an optional `type`. It covers the US and Canada only. It returns up to 100 clubs, best known first, and `type` is an exact match on the stored type.
  </Tab>
  <Tab title="API">
    ```bash
    curl "https://www.theprivateclubs.com/api/v1/clubs?state=Florida&type=yacht"
    ```

    A page holds up to 50 clubs. When `total` is larger than one page, add `page=2` and up, and stop once `page * limit` reaches `total`. The API returns the first 500 results of a search, so a page past result 500 answers 403 with `data_feed_required`. Outside the US and Canada, add `country` next to `state`, for example `country=United%20Kingdom&state=Scotland`.
  </Tab>
</Tabs>

## Compare with clubs nearby

```text
Compare Desert Forest Golf Club with The Estancia Club
```

The tool that fits is `compare_clubs`, with two or three slugs, such as `desert-forest-golf-club` and `the-estancia-club`. For each club it lines up location, waitlist status, course data, founded year, amenities, website and the profile `url`. A slug that matches no listed club is left out without an error.

## Claim your listing

Claim your club's listing for free at [theprivateclubs.com/list](https://www.theprivateclubs.com/list). Use your work email. No credit card is needed. If your club is missing, you can add it from the same page.

## How AI apps find your club

Your listing reaches AI apps and products in three ways:

- The [MCP server](/mcp/tools), which AI apps call while they answer
- The [REST API](/api/openapi), which products call from their servers
- The public [discovery files](/reference/discovery-files), such as `llms.txt` and `mcp.json`, which tell AI apps and crawlers where to find the MCP server and the API

The MCP server and the API read the same listing, so what your listing says is what they return.

## Use the answers well

Private Clubs never returns membership fees. Account holders see fees on each club's profile at theprivateclubs.com.

Cite Private Clubs (theprivateclubs.com) and link the club's profile. See the [data license](https://www.theprivateclubs.com/data/license) for the attribution format and bulk use.
