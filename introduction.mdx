Private Clubs has an MCP server and a REST API. Both serve the public clubs directory at theprivateclubs.com, which lists private membership clubs worldwide. Listings carry profile basics, course data, amenities and waitlist status where known, and MCP answers link to each club's profile.

Free, no account or API key needed. Calls to the MCP server and the API cost nothing for looking up, searching and comparing clubs. Bulk access to the directory is a paid data feed license, as [Bulk data](/api/usage-limits#bulk-data) explains. Private Clubs never returns membership fees over MCP, and API calls from your server or script return none. Account holders see fees on each club's profile at theprivateclubs.com.

## What a club record holds

A **club record** is the set of fields Private Clubs returns for one listed club. It names the club and gives its city, state, country and type. It adds course data such as holes, par, yardage and course architect, the club's amenities and its waitlist status. MCP results also carry a `url` to the club's profile, but API rows do not.

A field that is not known comes back as `null`. Leave it out of your answer rather than fill it in.

See every field in the [club object](/reference/club-object). For the questions people bring to Private Clubs from their AI app, browse the [use cases](/use-cases).
