Each page shows three questions people ask about clubs, the Clubs tool that answers each one and a starting prompt you can adapt. Every example uses the free Clubs MCP and needs no account.

<CardGroup cols={2}>
  <Card title="Members" icon="users" href="/use-cases/members">
    Search clubs, compare a shortlist and check whether a waitlist is open.
  </Card>
  <Card title="Club teams" icon="building" href="/use-cases/clubs">
    Read your profile as AI apps see it and compare it with clubs nearby.
  </Card>
  <Card title="Brands and creators" icon="sparkles" href="/use-cases/brands-and-creators">
    List the clubs of one type in a state before you plan outreach or research.
  </Card>
  <Card title="Real estate agents" icon="briefcase" href="/use-cases/real-estate-agents">
    Name the clubs in a town, check membership status and compare golf courses for a buyer.
  </Card>
  <Card title="Home buyers" icon="home" href="/use-cases/home-buyers">
    Find the golf clubs in a town and check a club before you buy a home there.
  </Card>
</CardGroup>

Clubs never returns membership fees. Account holders see fees on each club's profile at theprivateclubs.com.
