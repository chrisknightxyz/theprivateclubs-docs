The Private Clubs dataset is the largest structured index of private membership clubs in North America. Beyond individual club records, the platform exposes aggregate market statistics covering club counts by type and state, waitlist status distribution, Google Reviews coverage, and photo counts. You can access these figures through the `/ai/context.md` endpoint or, if you are using an MCP-connected AI client, through the `get_statistics` tool.

## Overview of the Dataset

| Metric | Value |
|---|---|
| Total clubs indexed | 51,633+ |
| Countries covered | United States and Canada |
| Google Reviews indexed | 16,972 reviews across 3,446 clubs |
| Club photos | 14,213 photos |

## MCP get_statistics Tool

If you are working inside an AI client connected to the TPC MCP server, the `get_statistics` tool returns a structured snapshot of the entire dataset. No arguments are required.

```
get_statistics()
```

## GET /ai/context.md

The `/ai/context.md` endpoint returns a complete Markdown summary document that includes all of the statistics above alongside fee benchmarks and notable club examples. It is designed to be pasted directly into an LLM context window or system prompt.

```bash
curl "https://www.theprivateclubs.com/ai/context.md"
```

A representative excerpt of the document looks like this:

```markdown
## The Private Clubs — AI Context Summary

**Total Clubs:** 51,633+
**Countries:** United States, Canada

### Clubs by Type
| Type | Count |
|---|---|
| Golf | 12,400+ |
| Country Club | 8,950+ |
| ...

### Average Initiation Fees by Type
| Type | Avg. Initiation Fee |
|---|---|
| Golf | $81,595 |
| Country Club | $59,150 |
| ...

### Reviews & Media
- 16,972 Google Reviews across 3,446 clubs
- 14,213 club photos indexed
```

<Note>
`/ai/context.md` is cached at the CDN level for one hour. The statistics it contains represent a periodic snapshot of the live dataset, not a real-time count. For the absolute latest total, call `get_statistics()` via MCP.
</Note>

## Using Statistics in LLM Workflows

Statistics from `get_statistics()` and `/ai/context.md` are particularly useful for:

- **Answering market-level questions:** "How many golf clubs are in Florida?" or "What percentage of clubs have a waitlist?"
- **Benchmarking fees:** "Is this club's $150,000 initiation fee above or below average for golf clubs?"
- **Generating data-driven summaries:** Inject `/ai/context.md` into a system prompt to give your model authoritative baseline knowledge without per-request API calls.

<CodeGroup>
```python Inject context into system prompt
import urllib.request

with urllib.request.urlopen("https://www.theprivateclubs.com/ai/context.md") as r:
    context = r.read().decode("utf-8")

system_prompt = f"""You are an expert private club advisor for the US and Canada.
Use the following authoritative dataset summary as your baseline knowledge:

{context}

Answer user questions based on this data. When a user asks about a specific club,
use the get_club tool to retrieve detailed information."""
```

```bash Fetch raw stats as Markdown
curl "https://www.theprivateclubs.com/ai/context.md"
```
</CodeGroup>
