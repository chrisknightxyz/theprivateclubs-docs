The ThePrivateClubs.com MCP server exposes five tools. Each tool is available to any connected MCP client — your AI assistant invokes them automatically based on the conversation, or you can call them explicitly in agent workflows. All tools hit the live database; no caching layer sits between your query and the platform data.

See [MCP Overview](/api/mcp-overview) for the endpoint URL and quick-start snippet, or [Connect a Client](/api/mcp-connect) for client-specific setup instructions.

## search_clubs

Search the directory of private membership clubs using structured filters. You can combine any number of parameters — the tool returns clubs that match all supplied criteria simultaneously. Results are ordered by relevance.

<ParamField query="state" type="string">
  Full US state name. Use `"Florida"` not `"FL"`. See [Conventions](/api/conventions#state-names) for the complete rule.
</ParamField>

<ParamField query="type" type="string">
  Club category. Must be one of the snake_case enum values below. See [Club Types Reference](/api/club-types-reference) for descriptions.

  `golf` · `country_club` · `yacht` · `aviation` · `equestrian` · `social` · `tennis` · `automotive` · `ski` · `fishing` · `beach` · `hunting` · `wellness` · `arts` · `adventure`
</ParamField>

<ParamField query="min_initiation_fee" type="number">
  Lower bound for initiation fee in USD. Clubs with undisclosed fees (null) are excluded when you supply this filter.
</ParamField>

<ParamField query="max_initiation_fee" type="number">
  Upper bound for initiation fee in USD.
</ParamField>

<ParamField query="waitlist_status" type="string">
  Filter by current membership availability. One of:
  - `open` — accepting applications (an application is still required)
  - `waitlist` — applications accepted for a waiting list
  - `by_invitation` — membership by sponsor or member referral only
</ParamField>

<ParamField query="query" type="string">
  Free-text search against club name, description, and tags.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Maximum number of results to return. Accepted range: 1–50.
</ParamField>

**Returns:** An array of club objects. Each object includes `id`, `name`, `slug`, `type`, `city`, `state`, `initiation_fee`, `annual_dues`, `waitlist_status`, `google_rating`, and `profile_url`.

**Example**

```json
// Ask your AI assistant:
// "Find golf clubs in Texas with initiation fees under $100,000 that are open for applications."

// The tool call looks like this:
{
  "tool": "search_clubs",
  "arguments": {
    "state": "Texas",
    "type": "golf",
    "max_initiation_fee": 100000,
    "waitlist_status": "open",
    "limit": 10
  }
}
```

## get_club

Retrieve the complete profile for a single private club by name or URL slug. This is the richest response in the API — it includes every data point ThePrivateClubs.com holds for the club.

<ParamField query="name" type="string" required>
  The club's full name (e.g. `"Augusta National Golf Club"`) or its URL slug (e.g. `"augusta-national-golf-club"`). Both formats are accepted.
</ParamField>

**Returns:** A single Club object with all fields populated. Key sections include:

<Expandable title="Full return shape">
  <ResponseField name="id" type="string">UUID for the club record.</ResponseField>
  <ResponseField name="name" type="string">Official club name.</ResponseField>
  <ResponseField name="slug" type="string">URL-safe identifier used in profile paths.</ResponseField>
  <ResponseField name="type" type="string">Club category in snake_case (e.g. `country_club`).</ResponseField>
  <ResponseField name="status" type="string">Publication status of the record.</ResponseField>
  <ResponseField name="tier" type="string">Data tier / completeness level.</ResponseField>

  <ResponseField name="city" type="string">City where the club is located.</ResponseField>
  <ResponseField name="state" type="string">Full state name.</ResponseField>
  <ResponseField name="address" type="string">Street address.</ResponseField>
  <ResponseField name="zip" type="string">ZIP code.</ResponseField>
  <ResponseField name="latitude" type="number">GPS latitude.</ResponseField>
  <ResponseField name="longitude" type="number">GPS longitude.</ResponseField>

  <ResponseField name="initiation_fee" type="number | null">Single initiation fee in USD, or `null` if undisclosed.</ResponseField>
  <ResponseField name="initiation_fee_min" type="number | null">Low end of initiation fee range.</ResponseField>
  <ResponseField name="initiation_fee_max" type="number | null">High end of initiation fee range.</ResponseField>
  <ResponseField name="annual_dues" type="number | null">Annual dues in USD, or `null` if undisclosed.</ResponseField>
  <ResponseField name="monthly_dues" type="number | null">Monthly dues in USD.</ResponseField>
  <ResponseField name="social_fee" type="number | null">Social membership fee, if applicable.</ResponseField>

  <ResponseField name="waitlist_status" type="string">One of `open`, `waitlist`, or `by_invitation`.</ResponseField>
  <ResponseField name="waitlist_years" type="number | null">Estimated years on waitlist, if available.</ResponseField>
  <ResponseField name="total_members" type="number | null">Current membership count.</ResponseField>
  <ResponseField name="member_capacity" type="number | null">Maximum membership capacity.</ResponseField>

  <ResponseField name="founded_year" type="number | null">Year the club was established.</ResponseField>
  <ResponseField name="amenities" type="array">List of amenity strings (e.g. `["Golf", "Tennis", "Pool", "Dining"]`).</ResponseField>
  <ResponseField name="tags" type="array">Descriptive tags (e.g. `["family-friendly", "championship-course"]`).</ResponseField>
  <ResponseField name="description" type="string">Long-form club description.</ResponseField>
  <ResponseField name="website" type="string">Club's official website URL.</ResponseField>

  <ResponseField name="holes" type="number | null">Number of holes. Golf and country_club types only.</ResponseField>
  <ResponseField name="par" type="number | null">Course par. Golf and country_club types only.</ResponseField>
  <ResponseField name="yardage" type="number | null">Total yardage.</ResponseField>
  <ResponseField name="slope" type="number | null">USGA slope rating.</ResponseField>
  <ResponseField name="rating" type="number | null">USGA course rating.</ResponseField>
  <ResponseField name="course_architect" type="string | null">Name of the course designer.</ResponseField>

  <ResponseField name="google_rating" type="number | null">Google Places rating (1.0–5.0).</ResponseField>
  <ResponseField name="google_review_count" type="number | null">Total number of Google reviews.</ResponseField>

  <ResponseField name="hero_image_url" type="string | null">Primary image URL.</ResponseField>
  <ResponseField name="logo_url" type="string | null">Club logo URL.</ResponseField>
  <ResponseField name="virtual_tour_url" type="string | null">Link to virtual tour, if available.</ResponseField>

  <ResponseField name="profile_url" type="string">
    Canonical URL on ThePrivateClubs.com, e.g. `https://www.theprivateclubs.com/clubs/florida/the-club-name`.
  </ResponseField>
</Expandable>

**Example**

```json
{
  "tool": "get_club",
  "arguments": {
    "name": "Winged Foot Golf Club"
  }
}
```

## get_fee_data

Retrieve aggregated initiation fee and annual dues statistics for a slice of the database. You can scope the aggregation to a specific state, a specific club type, or both.

<ParamField query="state" type="string">
  Full state name (optional). Limit aggregation to clubs in this state.
</ParamField>

<ParamField query="type" type="string">
  Snake_case club type (optional). Limit aggregation to clubs of this type.
</ParamField>

**Returns:** A statistics object with the following fields for both `initiation_fee` and `annual_dues`:

<ResponseField name="initiation_fee" type="object">
  <Expandable title="Fee statistics fields">
    <ResponseField name="average" type="number | null">Mean fee across matching clubs with disclosed fees.</ResponseField>
    <ResponseField name="median" type="number | null">Median fee.</ResponseField>
    <ResponseField name="min" type="number | null">Lowest disclosed fee.</ResponseField>
    <ResponseField name="max" type="number | null">Highest disclosed fee.</ResponseField>
    <ResponseField name="count" type="number">Number of clubs included in the calculation.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="annual_dues" type="object">
  <Expandable title="Dues statistics fields">
    <ResponseField name="average" type="number | null">Mean annual dues across matching clubs with disclosed dues.</ResponseField>
    <ResponseField name="median" type="number | null">Median annual dues.</ResponseField>
    <ResponseField name="min" type="number | null">Lowest disclosed annual dues.</ResponseField>
    <ResponseField name="max" type="number | null">Highest disclosed annual dues.</ResponseField>
    <ResponseField name="count" type="number">Number of clubs included in the calculation.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Clubs with undisclosed (null) fees are excluded from all calculations. The `count` field tells you how many clubs had fee data available in your filtered set.
</Note>

**Example**

```json
// "What are average golf club initiation fees in California?"
{
  "tool": "get_fee_data",
  "arguments": {
    "state": "California",
    "type": "golf"
  }
}
```

## get_statistics

Retrieve a market-wide overview of the ThePrivateClubs.com database. This tool takes no parameters and returns aggregate counts that give a bird's-eye view of the entire directory.

**Parameters:** None.

**Returns:**

<ResponseField name="total_clubs" type="number">Total number of club records in the database.</ResponseField>

<ResponseField name="by_type" type="object">
  A map of club type → count, e.g. `{ "golf": 1240, "country_club": 890, "yacht": 145, … }`.
</ResponseField>

<ResponseField name="by_state" type="object">
  A map of full state name → count, e.g. `{ "Florida": 320, "California": 280, … }`.
</ResponseField>

<ResponseField name="by_waitlist_status" type="object">
  A map of waitlist status → count, e.g. `{ "open": 1100, "waitlist": 600, "by_invitation": 400 }`.
</ResponseField>

**Example**

```json
// "How many private clubs does ThePrivateClubs.com list?"
{
  "tool": "get_statistics",
  "arguments": {}
}
```

## find_clubs_by_criteria

Search for clubs using a natural-language description of what you're looking for. The tool parses your plain-English criteria and maps them onto the structured database. Use this when you want to express complex requirements without constructing a multi-parameter filter manually.

<ParamField query="criteria" type="string" required>
  A free-text description of the ideal club. Be as specific or as general as you like. Examples:
  - `"family-friendly golf club in Florida under $50k initiation with tennis courts"`
  - `"exclusive yacht club in New England accepting new members"`
  - `"wellness or social club in New York City with a waiting list under 2 years"`
</ParamField>

**Returns:** An array of matching club objects (same shape as `search_clubs` results), ranked by how well each club fits your criteria. The matching engine considers location, type, fee ranges, amenities, and membership status.

**Example**

```json
{
  "tool": "find_clubs_by_criteria",
  "arguments": {
    "criteria": "beachfront club in Southern California with sailing and no initiation fee over $25,000"
  }
}
```

<Note>
  `find_clubs_by_criteria` is best for exploratory queries and early-stage research. For precise, reproducible filters — such as in an agent workflow or a saved search — use `search_clubs` with explicit parameters instead.
</Note>
