`GET /ai/clubs.json` is the primary endpoint for querying The Private Clubs dataset. It is designed for structured, machine-readable consumption and returns rich club data — including fees, amenities, waitlist status, and founding year — in a consistent JSON envelope. The endpoint is public, requires no authentication, and supports filtering by club type and US state alongside standard pagination controls.

## Endpoint

```
GET https://www.theprivateclubs.com/ai/clubs.json
```

## Query Parameters

<ParamField query="type" type="string">
  Filter clubs by type. Must be one of the values from the club type enum below. Omit this parameter to return clubs of all types.

  **Allowed values:** `golf`, `country_club`, `yacht`, `aviation`, `equestrian`, `social`, `tennis`, `automotive`, `ski`, `fishing`, `beach`, `hunting`, `wellness`, `arts`, `adventure`
</ParamField>

<ParamField query="state" type="string">
  Filter clubs by US state. Use the full state name (e.g., `Florida`, `New York`, `California`). Do not use abbreviations.
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to return, starting from `1`. Use in combination with `limit` to paginate through large result sets.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  Number of clubs to return per page. Maximum value is `500`. Set this to the maximum when fetching large datasets to minimise the number of requests required.
</ParamField>

## Response Schema

### Top-level object

```json
{
  "meta": { ... },
  "clubs": [ ... ]
}
```

### meta object

<ResponseField name="meta" type="object">
  Pagination metadata for the current response.

  <Expandable title="meta fields">
    <ResponseField name="meta.total" type="integer">
      Total number of clubs matching the current filter, across all pages.
    </ResponseField>

    <ResponseField name="meta.page" type="integer">
      The current page number returned in this response.
    </ResponseField>

    <ResponseField name="meta.pages" type="integer">
      Total number of pages available for the current filter and `limit` combination.
    </ResponseField>

    <ResponseField name="meta.source" type="string">
      Always `"ThePrivateClubs.com"`. Identifies the data source.
    </ResponseField>
  </Expandable>
</ResponseField>

### clubs array

<ResponseField name="clubs" type="array">
  Array of club objects matching the current filter and page.

  <Expandable title="club object fields">
    <ResponseField name="name" type="string">
      The full display name of the club (e.g., `"Admirals Cove"`).
    </ResponseField>

    <ResponseField name="url" type="string">
      Canonical URL for the club's profile page on ThePrivateClubs.com. Follows the pattern `https://www.theprivateclubs.com/clubs/{state-slug}/{club-slug}`.
    </ResponseField>

    <ResponseField name="type" type="string">
      The primary club type, from the same enum used as the `type` query parameter (e.g., `"golf"`, `"country_club"`, `"yacht"`).
    </ResponseField>

    <ResponseField name="location" type="object">
      Geographic location of the club.

      <Expandable title="location fields">
        <ResponseField name="location.city" type="string">
          City where the club is located (e.g., `"Jupiter"`).
        </ResponseField>

        <ResponseField name="location.state" type="string">
          Full state name (e.g., `"Florida"`).
        </ResponseField>

        <ResponseField name="location.country" type="string">
          ISO 3166-1 alpha-2 country code. Currently `"US"` or `"CA"`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="fees" type="object">
      Financial membership costs for the club.

      <Expandable title="fees fields">
        <ResponseField name="fees.initiation_fee_usd" type="integer | null">
          One-time initiation fee in US dollars. A `null` value means the fee is not publicly available — it does **not** mean the fee is zero. See [Data Conventions](/api/conventions) for guidance on displaying null fees.
        </ResponseField>

        <ResponseField name="fees.annual_dues_usd" type="integer | null">
          Annual membership dues in US dollars. A `null` value means the amount is not publicly disclosed.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="membership" type="object">
      Membership status and historical information.

      <Expandable title="membership fields">
        <ResponseField name="membership.waitlist_status" type="string | null">
          Current waitlist status. One of `"open"`, `"waitlist"`, or `"by_invitation"`. May be `null` if the status is unknown. Note that `"open"` still requires a formal application — it simply means applications are currently being accepted.
        </ResponseField>

        <ResponseField name="membership.member_count" type="integer | null">
          Total number of members. Often `null` as clubs rarely publish this publicly.
        </ResponseField>

        <ResponseField name="membership.founded_year" type="integer | null">
          The year the club was established (e.g., `1987`). May be `null` if not recorded.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="amenities" type="array">
      Array of amenity strings available at the club (e.g., `["golf", "tennis", "pool", "dining"]`). The values are free-form descriptive strings.
    </ResponseField>
  </Expandable>
</ResponseField>

## Paginating Through All Results

Use the `meta.pages` value from the first response to iterate through the full result set:

<CodeGroup>
```python Python
import urllib.request, json, time

def fetch_all_clubs(type=None, state=None):
    base = "https://www.theprivateclubs.com/ai/clubs.json"
    params = f"limit=500&page=1"
    if type:
        params += f"&type={type}"
    if state:
        params += f"&state={state.replace(' ', '+')}"

    all_clubs = []
    page = 1

    while True:
        url = f"{base}?{params.replace('page=1', f'page={page}')}"
        with urllib.request.urlopen(url) as r:
            data = json.loads(r.read())

        all_clubs.extend(data["clubs"])
        if page >= data["meta"]["pages"]:
            break
        page += 1
        time.sleep(0.1)  # be a polite client

    return all_clubs
```

```javascript JavaScript
async function fetchAllClubs({ type, state } = {}) {
  const base = "https://www.theprivateclubs.com/ai/clubs.json";
  const params = new URLSearchParams({ limit: 500, page: 1 });
  if (type) params.set("type", type);
  if (state) params.set("state", state);

  const allClubs = [];
  let page = 1;

  while (true) {
    params.set("page", page);
    const res = await fetch(`${base}?${params}`);
    const data = await res.json();
    allClubs.push(...data.clubs);
    if (page >= data.meta.pages) break;
    page++;
    await new Promise(r => setTimeout(r, 100));
  }
  return allClubs;
}
```
</CodeGroup>

<Tip>
Always set `limit=500` when paginating to minimise the number of round trips. At 100 requests/minute, you can page through the entire dataset of 51,633+ clubs in under 2 minutes with `limit=500`.
</Tip>
