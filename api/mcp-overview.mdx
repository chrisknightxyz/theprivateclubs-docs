The Private Clubs exposes its entire database of private membership clubs through a [Model Context Protocol (MCP)](https://modelcontextprotocol.io) endpoint. This lets AI assistants, coding agents, and chatbots query real-time club data — fees, waitlists, amenities, ratings, and more — without any API keys or OAuth flows. If your tool speaks MCP, you can point it at the endpoint and start asking questions about private clubs in seconds.

## Endpoint

| Property  | Value                                          |
|-----------|------------------------------------------------|
| URL       | `https://www.theprivateclubs.com/api/mcp`      |
| Transport | Streamable HTTP (SSE)                          |
| Auth      | None required                                  |

<Note>
  No API key, no OAuth, no headers. Just point your MCP client at the URL above and you're connected.
</Note>

## What You Can Do

Once connected, your AI tool gains five purpose-built tools for exploring private club data:

| Tool | What it does |
|------|-------------|
| [`search_clubs`](/api/mcp-tools#search-clubs) | Filter clubs by state, type, fee range, and waitlist status |
| [`get_club`](/api/mcp-tools#get-club) | Retrieve a full club profile by name or URL slug |
| [`get_fee_data`](/api/mcp-tools#get-fee-data) | Aggregate fee statistics by state and/or club type |
| [`get_statistics`](/api/mcp-tools#get-statistics) | Market-wide overview: total clubs, type counts, state breakdowns |
| [`find_clubs_by_criteria`](/api/mcp-tools#find-clubs-by-criteria) | Natural-language membership search |

## Quick Start

Add the server to your MCP client configuration. The snippet below works for Claude Desktop and Claude Code — see [Connect a Client](/api/mcp-connect) for Cursor, Windsurf, GitHub Copilot, n8n, and Notion AI.

```json mcp_config.json
{
  "mcpServers": {
    "theprivateclubs": {
      "url": "https://www.theprivateclubs.com/api/mcp"
    }
  }
}
```

After saving, restart your client and ask something like:

> *"Find me golf clubs in Florida with initiation fees under \$50,000 that are currently accepting applications."*

Your AI tool will call `search_clubs` under the hood and return matching clubs sourced directly from ThePrivateClubs.com.

## When to Use the MCP Integration

The MCP integration is the right choice when you are:

- **Building an AI assistant** that answers questions about private club memberships, fees, or availability
- **Creating a research agent** that compares clubs across states or types
- **Prototyping a chatbot** for a real-estate, relocation, or lifestyle application
- **Exploring data** interactively inside Cursor or Windsurf while building a club-search feature

If you need programmatic, non-AI access to the same data, use the [REST API](/api) instead.

## Data Freshness

All five MCP tools query the live ThePrivateClubs.com database. Fee ranges, waitlist statuses, Google ratings, and amenity lists reflect the most current data available on the platform. According to ThePrivateClubs.com, club records are updated continuously as new information becomes available.
